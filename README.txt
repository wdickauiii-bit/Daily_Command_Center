DAILY COMMAND CENTER — PHONE APP / PWA

WHAT THIS IS
This is an installable Progressive Web App (PWA). Once hosted on an HTTPS website,
you can add it to your iPhone/iPad or Android home screen and launch it like a normal app.

PHONE INSTALLATION
iPhone / iPad:
1. Upload this folder to an HTTPS host.
2. Open the app URL in Safari.
3. Tap Share.
4. Tap "Add to Home Screen".
5. Tap Add.

Android:
1. Upload this folder to an HTTPS host.
2. Open the app URL in Chrome.
3. Tap the browser menu.
4. Choose "Install app" or "Add to Home screen".

HOSTING OPTIONS
Any static HTTPS host works, including GitHub Pages, Netlify, Cloudflare Pages,
Vercel, or a normal web host. Upload the contents of this folder without changing
the relative file structure.

INCLUDED
- All Fall 2026 Masterlist assignment/event data from page 2 of the supplied tracker.
- Grades and scores excluded.
- Daily, weekly, and monthly planning.
- Add/edit/delete assignments and personal events.
- Daily habits, completion tracking, and streaks.
- Exam countdowns and alert banners.
- One-click study plans before exams.
- Offline caching after the first successful online load.
- Home-screen installation metadata and app icons.
- Local browser persistence plus JSON backup/import.

DATA STORAGE
Your planner changes are stored on the device/browser where you use the app.
Use Settings > Export backup to move or safeguard your data.

NOTIFICATIONS
The app can request browser notifications while it is open. Reliable scheduled
notifications while the app is fully closed require a push-notification backend
(or packaging as a native app with a local-notification plugin). That is a separate
deployment step.
